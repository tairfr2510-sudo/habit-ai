# HabitAI

HabitAI הוא מעקב הרגלים מודרני ועיצובי שמסייע לך לבנות שגרות בריאותיות, לשמור על עקביות ולראות התקדמות בצורה ברורה.

הפרויקט נועד לאנשים שמעוניינים לפתח הרגלים טובים דרך ממשק פשוט, אינטואיטיבי ותומך ב-AI.

## למה זה שווה?

- מעקב אחרי הרגלים יומיים ושבועיים
- ריצ'רד של רצפים והתפתחות
- דשבורד התקדמות וגרפים ברורים
- סיוע של מאמן AI לתובנות והנחיות
- שמירה מקומית של הנתונים so your progress stays available

## פיצ'רים עיקריים

- הוספה, סימון ומחיקה של הרגלים
- מעקב אחרי רצף ימים והגעה ליעדים שבועיים
- תצוגת התקדמות עם גרפים
- אינטגרציה עם AI לקבלת תובנות מותאמות
- ממשק רספונסיבי ונעים לשימוש

## טכנולוגיות

- React 19
- Vite
- Tailwind CSS
- Recharts
- Lucide React

## איך מריצים locally

```bash
npm install
npm run dev
```

## איך להפעיל תובנות AI

הקריאה ל-Gemini יוצאת ישירות מהקוד בצד לקוח (בלי שרת ביניים), עם מפתח שנקרא ממשתנה
הסביבה `VITE_GEMINI_API_KEY`.

1. הוסיפו קובץ `.env.local` בשורש הפרויקט עם `VITE_GEMINI_API_KEY=<המפתח שלכם>` (הקובץ לא מחויב ב-git).
2. הריצו `npm run dev` והתחילו לעבוד - `npm run build` צורב את המפתח לתוך חבילת ה-JS.

**חשוב לדעת:** מכיוון שהמפתח נצרב בתוך קוד ה-JS (כולל בתוך ה-APK של האפליקציה בטלפון), מי
שיש לו גישה לקובץ (למשל דרך פירוק APK, או דרך ה-devtools אם האתר יתפרסם באינטרנט) יכול
עקרונית לחלץ אותו ולהשתמש במכסת ה-Gemini שלכם. זו החלטה מודעת שמתאימה לאפליקציה אישית
שלא מתפרסמת בפומבי. **אם בעתיד תרצו לפרסם את האתר באינטרנט או בחנות אפליקציות, כדאי לחזור
לגישה עם שרת ביניים** שמסתיר את המפתח (למשל Netlify Function) - ניתן למצוא גרסה כזו
בהיסטוריית ה-git של הפרויקט.

## הפעלת אפליקציה + התראות אמיתיות בטלפון (Capacitor)

התזכורות שרצות בדפדפן (`setInterval` בתוך React) פועלות רק כשהטאב פתוח - ברגע שנועלים
את הטלפון או סוגרים את הדפדפן הן מפסיקות. כדי לקבל התראה אמיתית גם כשהאפליקציה סגורה,
הפרויקט עטוף עם [Capacitor](https://capacitorjs.com) ומתזמן תזכורת יומית ישירות במערכת
ההפעלה של הטלפון (`@capacitor/local-notifications`), בקובץ `src/lib/nativeReminders.js`.

תיקיית `android/` כבר נוצרה ומוכנה בריפו. כדי לבנות ולהתקין על טלפון:

1. דרישות: [Android Studio](https://developer.android.com/studio) מותקן (כולל JDK 17 ו-Android SDK - Android Studio מציע להתקין אותם אוטומטית בהתקנה הראשונה).
2. בנו את גרסת הווב העדכנית וסנכרנו אותה לפרויקט האנדרואיד:
   ```bash
   npm run build
   npm run cap:sync
   ```
3. פתחו את הפרויקט ב-Android Studio:
   ```bash
   npm run cap:open:android
   ```
4. בתוך Android Studio: חברו טלפון פיזי (עם USB debugging מופעל) או פתחו אמולטור, ולחצו Run ▶️.
5. באפליקציה, לחצו "הפעל התראות" במסך "ניהול הרגלים" - זה יבקש הרשאת התראות מהמערכת
   ויתזמן תזכורת יומית חוזרת בשעה שנבחרה. שינוי השעה בהגדרות מעדכן אוטומטית את התזמון.

**חשוב:** כל פעם שמשנים קוד ורוצים לראות את זה באפליקציה המותקנת, צריך לחזור על שלב 2
(`npm run build && npm run cap:sync`) ואז להריץ שוב מ-Android Studio.
